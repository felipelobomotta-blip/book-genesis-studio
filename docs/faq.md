# Questions writers ask

**What do I actually get?**
A set of instructions that your AI agent follows to write a book with you: it plans the story, writes every chapter, has simulated readers and an editor-like auditor critique it, revises, and prepares the logline, blurb, synopsis, query letter and cover brief. Everything is saved as files in a folder you own.

**Do I need to know how to code?**
You need an AI agent that can read and write files (Claude Code, Codex, OpenCode, Hermes, OpenClaw and others) and one command to install the skill. After that you talk to your agent in plain words, in your own language.

**How much of the book is mine?**
The idea, every decision you make at the check-ins, and anything you change. By default the agent stops after each phase and after every few chapters and asks "ok, or what should change?". You can also say "go to the end" and it finishes on its own, writing down every assumption it made so you can review them.

**Will it write a bestseller?**
That is the goal it is built around, not a promise. It uses measured patterns from books readers finish, and it is critical of its own work in ways most AI writing tools are not. Whether a book sells depends on things no workflow controls.

**Why should I trust its criticism?**
Because the readers who judge the book never see the plan, the target score, or earlier scores, and the revision is kept only if those blind readers prefer it. Each report says how independent the critics were: best when a second AI tool from another company reads the chapters. It is still simulated reading; the report says so.

**How long is the book?**
Full commercial length for the genre unless you ask for a novella, a short novel or a serial. The agent will not call a book complete while it is under its planned length.

**What languages?**
The book is written in the language of your idea. Research looks for comparable books in that language. Machine-sounding prose is checked with lists for English and Brazilian Portuguese; other languages use the English list.

**What does it cost?**
Book Genesis is free and open source. The writing uses your agent's own plan or API quota; a full book uses a lot of it. Measured time and cost per book will be published in the casebook as runs complete.

**Can I see a book it made?**
Yes: [Vicente, O Lago das Mensagens](https://github.com/felipelobomotta-blip/book-genesis-studio/releases/tag/case-vicente-v1), 32 chapters, EPUB and PDF, made with an earlier version. Its score is self-assessed and no outside reader has reviewed it yet.

**Can I use only part of it?**
Yes. The beta reader, editorial package and literary agent panel skills work on any manuscript you already have.

**Fiction only?**
Fiction and memoir are what it is tuned and tested for. Nonfiction works, but its patterns are not calibrated yet.
