# Independent creative revision acceptance

The author approved fixing revision isolation and testing existing problem
passages with Codex gpt-5.6-luna high. The complete book and automation remain
paused. Existing release files, original attempts, scores and gates are immutable.

## Problem and decision

Shared issue IDs currently define an atomic publication group. They are useful
for assembling an editorial dispatch, but do not prove that every candidate
depends on every other candidate. One valid negative check discarded fifteen
otherwise viable candidates in the actual run.

Keep the existing coordinated path. After a **valid negative repair review**,
derive conservative dependency hints from that review's citations of companion
proposals in each chapter's canon/causality check. Shared issue IDs alone never
create dependency edges. A citation is only a conservative hint, not proof of
necessity or acceptance. Collapse cycles into atomic units and process other
units after their prerequisites. A failed unit blocks its dependents only.

Each eligible unit gets a fresh manifest of the complete CURRENT accepted book
with only that unit's proposals substituted. It must pass the SAME four repair
checks and fresh four-reader anonymous preference vote before guarded atomic
publication. An earlier passing chapter check is never reused as approval of a
different assembled book. A newly found dependency blocks that unit rather than
granting an exception. No repeated polling of unchanged rejected units.

Original negative reviews and group outcomes stay immutable. Each unit binds its
parent manifest/review/partition evidence, candidates and fresh native evidence.
Resuming verifies hashes, remaining prerequisites and publication recovery.
Legacy manifests preserve their old interpretation. New passes explicitly opt in.

## Experiment and acceptance

Re-use the actual Luna-authored chapter 4, 8, 18 and 22 candidates as imported
experimental inputs, recording raw response/stage provenance. Fresh Luna high
reviews and comparisons run in a dedicated evaluation project. Existing book
prose supplies canon; no complete-book generation, measurement or export occurs.
Only the evaluation copy can receive accepted edits.

Technical acceptance: an independent valid candidate can publish while a bad
candidate stays original; dependent repairs publish together or remain blocked;
negative preference, changed canon, altered evidence, malformed reports and
interruption never yield fabricated approval. Literary acceptance remains the
unchanged repair checks and preference rule. Report all negative results and
scope limits; no whole-book score or best-seller claim follows from this pilot.
