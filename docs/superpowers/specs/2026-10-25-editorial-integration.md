# Evidence-backed editorial integration

The user approved incorporating the strongest mechanisms in the 29-entry competitive study. Keep the current Python native-host architecture, book-local immutable journal, isolated reviewers, existing production and literary gates, and recoverable publication transactions. Reimplement mechanisms locally; do not vendor commercial internals or unreviewed third-party source. See `docs/research/competitive-study-20261025.md` for evidence and limits.

## Deliverable

1. Source-selected repair evidence: a new versioned group-review contract selects exact sentence/block spans by IDs. The controller supplies literal quotes; semantic support remains an explicit reviewer obligation and existing changed-mechanism/negative-verdict checks remain. Legacy report schemas and packets remain verifiable.
2. Planning and writing guidance shared by host skills and native workflow: explicit scene goals, resistance, change, cost, consequence; arc diversity; early representative voice calibration; author constraints; nonfiction source-before-claim policy. No universal beat percentages, stylistic bans, score exposure to writers, or invented research.
3. Deterministic continuity context compiled from accepted chapter sources: dated per-chapter source IDs and hashes, precise handoff, provisional summaries kept separate, no future chapter exposure. Keep the full canonical prose already supplied; retrieval must not erase unresolved constraints.
4. Dependency-aware revision planning instructions and a focused prose diagnosis contract, preserving whole-book dependency checks and blind preference before promotion.
5. A read-only author progress command: actual phase, active request, elapsed time, accepted chapters, measured words, delivery and literary statuses; no fabricated thinking or percentage. No model calls for status.
6. Attribution/adoption matrix covers all studied entries, identifies existing equivalents and explicitly deferred items (e.g. audio/cover generation, SaaS collaborative UI and PDF geometry are separate capabilities, not falsely declared implemented).
7. Regression tests and new immutable local beta package. No historical-book changes, installed-cache overwrite, publication or readiness claim. Literary gain requires a new blinded native comparison/full-book trial after technical checks.

## Acceptance

Adversarial evidence tests reject unknown/wrong-version/repeated IDs and unchanged-regression accusations. Old packet hashes remain valid. Workflow tests prove guidance reaches intended writers/editors without reaching blind readers or leaking quality targets. Status never equates export with literary approval. The complete existing suite and installer verification pass. New archive includes every runtime/reference file and uses a fresh version.

Current baseline: beta6 delivered 24 chapters, 83,517 words and EPUB; final automated literary result 72.52/100, not approved. No implementation may change that historical result or its calibration.
