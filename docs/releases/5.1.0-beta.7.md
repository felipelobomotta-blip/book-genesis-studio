# Book Genesis 5.1.0-beta.7

Your creativity. Your agent. Your book.

Book Genesis is an open-source writing workflow inside your existing agent. Describe an idea; the workflow plans, drafts chapters, runs simulated reader reviews and an editorial audit, performs bounded revisions, and exports Markdown and EPUB. Files and progress live in your book workspace.

## Install

Codex, in a terminal:

```bash
codex plugin marketplace add felipelobomotta-blip/book-genesis-studio --ref v5.1.0-beta.7
codex plugin add book-genesis@book-genesis
```

Claude Code, inside a session:

```text
/plugin marketplace add felipelobomotta-blip/book-genesis-studio
/plugin install book-genesis@book-genesis
```

Restart the session, select Book Genesis and describe the book. Python 3.10+ and local execution tools are required. Your host's subscription, permissions and quotas apply. [Detailed guide](../plugins.md).

## What changed

- Native host manifests and one reproducible ZIP with an explicit payload allowlist.
- Scene goals, resistance, decisions, cost and consequences; character knowledge boundaries and arc changes.
- Role-specific planning, writing and revision guidance with voice calibration and source-before-claim nonfiction instructions.
- Full accepted-source provenance and exact chapter handoffs. Provisional summaries are labelled.
- Source-selected review quotations with fail-closed validation, immutable attempts and compatible historical evidence.
- Clearer saved activity, bounded recovery and honest export-versus-literary outcomes.
- Desktop requirement, support/privacy/usage pages and directory review materials.

## Evidence and limits

Historical beta6 produced a revised/exported 24-chapter, 83,517-word draft with a final automated literary score of 72.52/100 and unmet literary gates. Beta7's native Luna/high diagnostic reviewed a complete 24-chapter revision packet and preserved a valid blocking result: two findings, 15 literal quotations. These are different experiments.

No new complete beta7 book above 90/100, human critical rating or sales result is claimed. Claude full-book compatibility and DeepSeek runtime compatibility remain separately unproven.
