# Bound native editor input without losing source prose

A real unattended Codex Luna/high trial completed 24 chapters and 84,687 words,
then failed at chapter21's first creative revision. Its prompt was1,076,097
characters. A separate native transport canary confirmed turn/start's1,048,576
character maximum. The preceding1,046,172-character chapter20 request succeeded.
Increasing the token context setting cannot lift this per-turn character cap.
The failed trial, native receipts, original manuscript and initial70.15/100
calibrated measurement remain failed/preserved. No final score or export resulted.

Small editor packets retain their existing bytes. A large editor context keeps
every complete current chapter, contract, craft reference, task and actual
proposed change. An almost-unchanged companion proposal can use exact line
replacements against its already-supplied complete original. Each replacement
includes its literal before/after prose; hashes bind both original and complete
candidate. Unchanged lines remain verbatim. A duplicated adjacent chapter can
reference the complete copy already in the same packet. Entirely rewritten
companions remain full text when that is smaller.

Before dispatch the decoder reconstructs every candidate and original context
field, checks source/candidate/full-context hashes, ranges and before text. No
summary, omitted chapter, external file access or new canon is substituted.
The packet explains the version distinction. The model still returns the entire
revised chapter. Whole-book dependency review, blind preference, guarded
publication and original native receipts retain their existing requirements.

The initial editor packet is capped at900,000 characters, leaving headroom for
the existing two-attempt producer-format repair. If lossless representation is
still too large, construction stops with an explicit size error before any new
native dispatch. It never silently truncates sources. This fixes duplicate-heavy
editor inputs; it does not claim arbitrary-length books fit a model's context.

The controller also checks the actual final controlled Codex packet after all
format feedback and any rejected producer response are attached. An oversized
turn receives a durable input_too_large checkpoint with native_dispatched=false,
complete frozen input evidence and the previous original response. No native
call or receipt is invented. An unchanged resume verifies that evidence and
keeps the same explicit block, preserving its reserved attempt slot. Other
explicit transports retain their own input rules. Native process lifecycle,
model selection and authentication are unchanged.

Regression coverage includes an actual1.73-million-character editor handoff,
full source/candidate reconstruction, bounded format retry, unchanged resume,
Unicode/newlines, insertion/deletion/replacement and tampered source rejection.
Installer and full regression verification are required before a native proof.
No real book or literary acceptance is implied by these component checks.
