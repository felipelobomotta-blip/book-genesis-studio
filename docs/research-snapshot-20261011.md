# Dated publisher metadata for autonomous intake

The native planning roles cannot browse. Earlier trials therefore supplied
comparison hypotheses but no checked external edition data, and an original
critic identified weak market evidence. This candidate gives intake a small
dated catalog of seven manually checked US English-language editions. It adds
no model call, network dependency, API credential or author question.

The catalog records title, author, publisher, format, publication date, ISBN,
pages, recorded publisher category and short paraphrases where the description
was inspected. Each entry links directly to its publisher page. For example,
the [Riverhead paperback of The God of the Woods](https://www.penguinrandomhouse.com/books/676637/the-god-of-the-woods-by-liz-moore/)
lists 576 pages and October 28, 2025; these facts concern that paperback edition,
not the hardcover, prose word count, current sales or a new manuscript's demand.

The complete source catalog is
`skills/book-genesis/references/research/english-fiction-metadata-20261011.json`.
Its checked date is October 11, 2026. This is manually gathered metadata,
not an execution of REA, a complete bestseller corpus or a live market survey.
The Searcher, The Last House Guest and The Marsh King's Daughter are historical
positioning anchors; no entry is represented as a currently ranking bestseller.
Publisher descriptions are publisher statements, not independent sales proof.

English intake receives the age, scope, limitations, original reference hash and
edition records. Other languages receive an explicit unavailable result.
Future-dated snapshots are unavailable. Intake must cite the provided source and
checked date for edition facts, select only relevant comparisons, state their
differences and retain uncertainty about relevance, demand and audience size.
Page counts cannot establish prose word counts or prose rhythm. The original
research specialist remains the method for broader live research in a tool-enabled
host. This small catalog does not establish coverage of other genres or markets.

Before the first intake call, the program freezes the exact metadata packet in
`work/research/reference-metadata.json`. Resume reuses the original observation
date and validates the facts against the bundled source. Phase 0 binds its hash
alongside the generated planning artifacts. Changed saved intake evidence blocks
resume before further role calls; the changed file remains preserved. Completed
resume retains the original packet and makes no new model call.

Tests exercise shipped edition metadata, language exclusion, old and future
dates, malformed sources, ISBN checksums, immutable resume and tamper refusal.
The existing complete revision/export/resume integration also checks the frozen
intake packet. No grading rule, target, calibration or earlier native evaluation
changes. Fresh native literary improvement remains unverified.

All 488 repository tests passed in 436.702 seconds and `verify-suite` passed.
These are implementation checks; they do not establish native literary improvement.
